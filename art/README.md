# Картины

Снимки картин для уровня-картины (`js/art.js`). Картины — в общественном достоянии (авторы умерли больше
70 лет назад), а точные фотографии двумерных картин в общественном достоянии сами не охраняются авторским
правом; на Wikimedia Commons они так и помечены.

| Файл | Картина | Источник |
| --- | --- | --- |
| `sunflowers.jpg` | Винсент ван Гог, «Подсолнухи» (Ваза с пятнадцатью подсолнухами), 1888. Лондонская Национальная галерея | [Vincent Willem van Gogh 127.jpg](https://commons.wikimedia.org/wiki/File:Vincent_Willem_van_Gogh_127.jpg), Wikimedia Commons, Public domain |

Снимок уменьшен до 800 px по ширине (ffmpeg, lanczos) и пересжат в JPEG. Уменьшенная копия в `js/art.js`
(48 × 60 точек) — среднее по площади (ffmpeg, `flags=area`).
