# Arkanoid GL

Арканоид на чистом WebGL2 и JavaScript, без сборки и зависимостей.

**Играть:** https://dinoel.github.io/arkanoid-gl/

- **Физика.** Мяч, ракетка и кирпичи — настоящие тела со столкновениями многоугольников; кирпичи бывают
  прямоугольные, круглые, ромбы, шестиугольники, треугольники; часть из них движется.
- **Осколки.** Разбитый кирпич разлетается на осколки; их можно ловить ракеткой. За каждый — очки
  (у прочных и взрывных больше), а поимки подряд, без пауз дольше секунды, умножают их до ×3.
- **Гравитация.** У кирпичей есть масса, и они искривляют траекторию мяча (клавиша <kbd>G</kbd>).
- **Приманка.** Если мяч долго не попадает по кирпичам (обычно когда остался последний), они начинают
  притягивать его всё сильнее — вокруг появляется «воронка». Попадание снимает притяжение.
- **Магнит.** Пока зажата кнопка мыши или пробел, ракетка заворачивает мяч к себе: можно вернуть его
  из-под потолка или подправить падение. Если подобран лазер, кнопка вместо этого стреляет.
- **Процедурные уровни.** Каждый уровень собирается из сида; сид можно задать в адресе: `?seed=12345`.
- **Звук.** Адаптивная процедурная музыка в шести стилях: synthwave, techno, drum'n'bass, lo-fi, trap и chiptune.
  У песни есть узнаваемая тема с ответом и разрешением; дроп возвращает её и исходную тональность,
  а в остальных секциях фразы открываются тактом темы и продолжают её вариациями.
  Бас подхватывает акценты бочки, арпеджио заполняет паузы мелодии, голоса аккордов движутся плавно.
  Ударные используют локально синтезированный банк с двумя уровнями динамики и чередующимися вариантами ударов.
  Клавишные реагируют на силу нажатия; стереолиды, ping-pong-эхо и реверберация создают пространство.
  Мультимяч, комбо и бонусы меняют плотность и яркость партий по тактам. Потеря мяча ведёт в брейк
  (нарастание сначала доигрывает до короткого дропа), на новом уровне прошлая песня плавно гаснет под
  начало новой; длительный высокий накал приближает дроп.
  Параметры музыки можно крутить в [Music Lab](https://dinoel.github.io/arkanoid-gl/music.html).
  Там же можно повторить песню по сиду, проверить игровые события и записать результат.
  Внешних загрузок, библиотек и чужих семплов нет: всё работает на Web Audio.
- **Глобальное освещение.** Radiance cascades: мягкие тени, цветные прожекторы на стенах, свет от огня
  и вспышек. Прожекторы висят выше кирпичей: лучи ложатся на их верх, а пол за кирпичом остаётся в тени.
  Качество подстраивается под скорость видеокарты; выключается клавишей <kbd>L</kbd>.
- **Цветомузыка.** Прожекторы играют музыку светом. Цвет берётся из нот по квинтовому кругу, как у Скрябина:
  аккорд перекрашивает весь зал. Нижние прожекторы горят цветом баса и бьют под бочку, верхние вспыхивают
  от малого барабана, по арпеджио бежит огонь, верхние лучи ведут мелодию. Лучи танцуют фигурами,
  которые меняются по тактам, а перед дропом свет мигает и гаснет.
- **Настройки** (<kbd>O</kbd>). Ползунки для свечения мяча: свет на поле, ореол, шлейф, яркость. По умолчанию
  мяч не светит, а только отбрасывает тень. Выбор запоминается в браузере.

## Управление

| | |
|---|---|
| мышь / <kbd>←</kbd> <kbd>→</kbd> | ракетка |
| клик / <kbd>пробел</kbd> | запуск мяча, лазер |
| зажать кнопку мыши / <kbd>пробел</kbd> | магнит: ракетка заворачивает мяч к себе (с лазером — стрельба) |
| <kbd>P</kbd> / <kbd>Esc</kbd> | пауза |
| <kbd>M</kbd> | музыка |
| <kbd>G</kbd> | гравитация |
| <kbd>L</kbd> | глобальное освещение |
| <kbd>O</kbd> | настройки |
| <kbd>N</kbd> | пропустить уровень |
| <kbd>R</kbd> | новая игра с новым сидом |

## Запуск локально

Нужен любой статический сервер, например:

```
python -m http.server 8000
```

и открыть http://localhost:8000/.

## Проверка музыки

Композитор и контракт светомузыки проверяются без зависимостей (Node.js 22+):

```
node --test --test-isolation=none tests/music.test.cjs
```

Для проверки настоящего Web Audio, Music Lab и WebGL нужен установленный Chromium/Chrome/Edge:

```
node tests/browser-smoke.cjs
```

Если браузер не найден автоматически, задайте путь к нему в переменной `BROWSER`.
Тест рендерит все шесть стилей через `OfflineAudioContext`, проверяет пики, стерео, освобождение голосов,
выключение реверберации вместе с мастер-громкостью, управление и прожекторы. Отчёт, скриншоты и
пример `music-showcase.wav` сохраняются в `.artifacts/` (не входит в Git).

Музыка и свет используют одни и те же события: все слышимые партии проходят через обёртки в `music.js`,
которые отправляют фактическую громкость, MIDI-ноту и длительность в `Music.lights()`.
`Music.clock()` остаётся на сетке аудиочасов; свинг смещает отдельные ноты, сохраняя тактовую сетку.
Новые инструменты следует подключать через эти обёртки, чтобы прожекторы оставались синхронными.
